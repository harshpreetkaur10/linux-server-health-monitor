# Linux Server Health Monitoring

## Project Description
This project uses Bash scripting to monitor basic Linux server health information.

## Project Features
- Displays current date and time
- Checks server hostname
- Displays system uptime
- Checks memory usage
- Monitors disk usage
- Displays CPU information

## Technologies Used
- Linux
- Bash Scripting
- Ubuntu
- GitHub

## How to Run

1. Open a Linux terminal.
2. Download or clone this repository.
3. Navigate to the project folder.
4. Run:

   chmod +x server-health.sh

5. Execute:

   ./server-health.sh

## Learning Outcomes
- Linux commands
- Bash scripting
- File permissions
- Server monitoring fundamentals
